Process camera frames in realtime with a JS worklet and pick a specific lens using [VisionCamera](https://visioncamera.margelo.com). For standard photo, video, or barcode capture, see the [with-camera](../with-camera) example.

## Launch your own

[![Launch with Expo](https://github.com/expo/examples/blob/master/.gh-assets/launch.svg?raw=true)](https://launch.expo.dev/?github=https://github.com/expo/examples/tree/master/with-vision-camera)

## 🚀 How to use

- Install packages with `yarn` or `npm install`.
- Run `yarn ios` or `yarn android` to build and run a development build. VisionCamera doesn't work in Expo Go or on web.
- Frame sizes and pixel formats are logged to the console.
