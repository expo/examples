Store strings, numbers, booleans, and ArrayBuffers synchronously, and encrypt an instance with AES-256, using [react-native-mmkv](https://github.com/margelo/react-native-mmkv). Hooks re-render the UI when a value changes.

## Launch your own

[![Launch with Expo](https://github.com/expo/examples/blob/master/.gh-assets/launch.svg?raw=true)](https://launch.expo.dev/?github=https://github.com/expo/examples/tree/master/with-mmkv)

## 🚀 How to use

- Install packages with `yarn` or `npm install`.
- Run `yarn ios` or `yarn android` to build and run a development build. MMKV doesn't work in Expo Go.
